# 分类 / Taxonomy

方便以后找组件、起名、建仓库时对齐。

| 层级 | 本库取值 | 说明 |
|------|----------|------|
| Domain | `ui` | 界面层，非业务逻辑 |
| Category | `feedback` | 用户反馈：确认 / 提示 / 通知 |
| Components | `confirm-modal`, `toast` | Confirm Dialog + Toast |
| Stack | `vanilla-js` | 零依赖，可进任意后台/插件 |
| Brand prefix | `yh-` | 烟火云可复用组件前缀 |

## 推荐仓库命名

- `yh-feedback` — 本库（Modal 确认 + Toast）
- `yh-*` — 后续同类：`yh-table`、`yh-form`…
